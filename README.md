# TeamWing — сайт

Сайт приложения TeamWing: главная, политика конфиденциальности, поддержка (ru / en / kk).
Адрес: https://warlockjohn.github.io/teamwing-site/

Тексты правятся в `_build.py`, потом `python3 _build.py` пересобирает HTML.
Публичная ссылка на бету — константа `BETA` в `_build.py` (пусто → вместо кнопки надпись «по приглашению").
